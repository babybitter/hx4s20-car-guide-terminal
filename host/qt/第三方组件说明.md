# 第三方组件与设计参考

本工程使用 PySide6 / Qt、pyserial、Pillow、fontTools；构建工具使用 PyInstaller。具体构建版本记录于源码根目录的 requirements-lock.txt。免安装目录的 LICENSES/ 附带所用组件安装包中的许可证与通知；重新分发时请一并保留。

Qt for Python：https://doc.qt.io/qtforpython-6/

界面布局与视觉层次参考 MICU-OmniProbe（https://github.com/zuoliangyu/MICU-OmniProbe）。本次使用 Qt 自行实现工作台界面，没有复制该仓库 React / Rust 源码、图标素材或品牌标识，不将它的协议功能作为本工程能力。

原上位机 Python 模块来自同一工作区的项目快照。中文字体由用户电脑提供或用户选择；本工程不随包复制 Windows 字体。原图片及素材清单沿用项目已有资源。

pyserial 3.5 的完整 BSD-3-Clause 许可证保存在根目录 `pyserial-LICENSE.txt`，来源为 [pyserial v3.5 官方许可证](https://github.com/pyserial/pyserial/blob/v3.5/LICENSE.txt)。构建时复制到免安装目录的 `LICENSES/pyserial/LICENSE.txt`；构建过程不需要联网获取许可证。
